# Agent Notes

## Active

- Every non-trivial change includes a decision record in the same change.
- A note records the decision, alternatives considered, consequences, and required verification.
- Update the owning note instead of creating a duplicate.

## Implemented

- Implemented notes describe shipped reality in the present tense.
- Remove migration plans and acceptance checklists after the decision ships.

## Archived

- Archived notes are frozen history.
- Never edit an archived note or treat it as current authority.
