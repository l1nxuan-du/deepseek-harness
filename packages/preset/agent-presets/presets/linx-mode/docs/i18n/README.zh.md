# i18n

[English](README.md) | 中文

## 约定

- 面向用户的 UI 文本由 locale 拥有。字符串必须经过带类型的本地化字典，不得硬编码显示文本。
- 保持 locale key 稳定，并让每个 key 关联到拥有它的界面。

## 术语

- 术语只定义一次，并在源码、文档与 UI 中使用同一术语。
- 记录不同 locale 之间有意保留的差异。

## 翻译流程

- 说明字符串如何提取、评审、翻译与发布。
- 将机器翻译与人工评审状态分开维护。

## 验证

- 检查缺失 key、未使用 key、占位符一致性以及回退行为。
- 在平台有要求时加入 locale 专属的格式化测试。
